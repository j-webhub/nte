# 스킬 레벨업 재료 수집 기록

수집일: 2026-10-20. 대상: 아카네 외 기존 23명. 기존 스킬 설명과 계수는 수정하지 않았습니다.

## 수집 범위

- 캐릭터별 일반 공격·바이레일·울티메이트·서포트 4종의 직접 강화 Lv.1→10.
- 각 단계의 비틀 코인, 강화 재료, 필드 재료, 주간 보스 재료, 필요한 캐릭터 돌파 단계.
- 23명 × 4종의 단계별 비용과 합계를 수집했습니다. 이번 자료 안에서는 캐릭터별 4종의 재료·수량이 동일했습니다.
- 고유 패시브 해금, 도시 스킬, 각성/공명의 추가 레벨, 캐릭터 레벨업과 돌파는 스킬 강화 합계에서 제외합니다.
- 아카네의 아크·콘솔·성장 자료는 앞선 사용자 요청에 따라 검토 상태를 유지합니다.

## 출처

- 각 캐릭터: `https://www.kaiden.gg/nte/characters/{id}/`. 23명 전원의 원자료 링크는 배포 JSON에 저장했습니다.
- 한국어 재료명: https://gamewith.ai/nte/ko/item
- 한국어 캐릭터 비교 표: `https://gamewith.ai/nte/ko/character/{id}`. 기존 17명 접근 가능, 이후 6명은 404이므로 비교 출처에서 제외했습니다.
- 기억의 영속성 한국어 명칭·레이븐 재료 계열: https://www.inven.co.kr/board/nte/6518/334?iskin=nte

모두 커뮤니티 자료입니다. 공식 검증 완료로 표시하지 않습니다.

## 출처 차이 처리

한국어 도감 일부 단계에 코인·재료 표기가 다른 항목이 있습니다. 원자료끼리 다른 부분은 `skill-material-discrepancies-20261020.json`에 보존했습니다.

Lv.8→9 비틀 코인은 한국어 도감의 125,000 대신 Kaiden의 100,000을 채택했습니다. Kaiden의 단계별 합계는 같은 페이지의 스킬 1종 총액 437,000과 일치합니다. 4종 합계는 1,748,000이며, 패시브 해금까지 포함한 별도 가이드의 1,818,000과 범위가 다릅니다.

강화 재료 계열은 캐릭터별 원자료에서 직접 가져왔습니다. 속성이나 등급으로 추정하지 않았습니다. 한국어 도감과 다른 재료가 있는 단계도 Kaiden에서 단계별 합계와 원자료 총계가 일치하는 구성을 채택했습니다.

## 파일과 재수집

- `skill-materials-20261020.json`: 수집한 재료표 항목.
- `skill-material-discrepancies-20261020.json`: 비교 출처와 다른 단계.
- `dist/data/nte-character-growth-v1.4.json`의 `skillUpgrades`: 공통 단계표·재료명·캐릭터별 계열·출처.
- `dist/js/features/characters/tabs/skill-growth.js`: 합계 계산과 출력.

명시적으로 재수집할 때 저장소 루트에서 실행합니다. 네트워크가 필요합니다.

```powershell
node scripts/collect-skill-materials.mjs
node scripts/import-skill-materials.mjs
node scripts/update-version.mjs
```

수집 스크립트는 연구 자료만 저장합니다. 가져오기 스크립트는 4종 스킬의 수량과 총액 일치 여부를 확인한 후 성장 JSON에 반영합니다. 다른 강화 비용 구조가 발견되면 중단하므로 별도 단계표를 추가해야 합니다.
